# AlchimistWorld — документация

Настольное приложение-помощник для homebrew-алхимии в D&D-кампании. Ведёт учёт реагентов и готовых зелий, показывает, что можно сварить из того, что есть, чего не хватает до известных рецептов, и хранит журнал экспериментов.

## Проблема

Ингредиентов и зелий в игре стало слишком много. Держать в голове, какие сочетания элементов у тебя собираются и какие рецепты из них выходят, уже не получается.

## Ключевые решения (кратко)

- **Стек:** Python 3.12+ и PySide6 (Qt 6). Логика полностью отделена от интерфейса, поэтому GUI можно переписать (GTK, TUI, веб), не трогая ядро.
- **Платформы:** Linux (основная), Windows, macOS: у части игроков не Linux.
- **Данные:** JSON-файлы для справочника, инвентаря и журнала, TOML для настроек. Файлы читаются и правятся руками (например в nvim), их удобно хранить в git.
- **Совместная игра:** у каждого игрока своя установка и свой инвентарь. Справочник (ингредиенты, зелья, рецепты) экспортируется в файл и передаётся другим.
- **Исходные данные:** справочник один раз собран из Obsidian-заметок кампании (`Алхимия/`), дальше ведётся в самом приложении и передаётся файлом.
- **Язык интерфейса:** русский, с заделом под перевод.

## Глоссарий

| Термин | Значение |
|---|---|
| Элемент | Одна из 7 магических стихий: Огонь, Вода, Воздух, Земля, Свет, Тьма, Магия |
| Единица элемента | Одна «порция» стихии. Реагент содержит от 1 до 5 единиц |
| Реагент / ингредиент | Предмет с набором единиц элементов: трава, эссенция, часть существа. В документации эти слова значат одно и то же |
| Основа | То, на чём варится зелье: жидкая, вязкая или взрывная. Считается, что основы у персонажа всегда есть |
| Рецепт | Пара «допустимые типы основы + мультимножество элементов» |
| Мультимножество элементов | Набор элементов с повторами, где порядок не важен. Пример: `{Огонь×2, Свет×1}` |
| Справочник (каталог) | Все известные ингредиенты и зелья, общие для партии |
| Инвентарь | Что лежит в сумке у конкретного игрока: реагенты и готовые зелья |
| Журнал | История варок и экспериментов |
| Набор | Инструменты, которыми варит персонаж: алхимика, травника или отравителя |
