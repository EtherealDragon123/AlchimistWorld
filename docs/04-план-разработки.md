# 04. План разработки

Каждый этап заканчивается чем-то рабочим, чем уже можно пользоваться или что можно проверить. Номера требований — из [02-требования.md](02-требования.md).

## Этап 0. Каркас проекта

- `git init`, `.gitignore`, `pyproject.toml`, структура папок из [03 §3](03-архитектура-и-данные.md#3-структура-репозитория).
- Окружение (`uv` или `venv`), зависимости: `pyside6`, `platformdirs`, `tomli-w`, `babel`; для разработки — `pytest`, `ruff`, `import-linter`.
- Контракты `import-linter` для слоёв и `pre-commit` с `ruff` + `import-linter`.
- GitHub Actions: `ruff` + `pytest` на трёх ОС.

**Готово, когда:** `pytest` зелёный на пустом тесте, `import-linter` ругается на пробный `import PySide6` в `core`.

## Этап 1. Ядро

- `core/elements.py`, `core/models.py`, `core/ids.py`.
- `core/rules.py`: проверки П-3.2, П-5.2, П-5.6 и разрешения наборов.
- `core/matcher.py`: `find_combinations`, сортировка, повторы, «почти готово».
- Тесты из [03 §9](03-архитектура-и-данные.md#9-тестирование), кроме импорта и хранения.

**Готово, когда:** все тесты ядра проходят на вручную заданных данных.

## Этап 2. Хранение и импорт

- `storage/`: пути, JSON-репозитории, атомарная запись, `.bak`, `schema_version`.
- `importers/obsidian.py` + команда `python -m alchimist import-obsidian` с `--dry-run` и отчётом.
- Отладочные CLI-команды: `alchimist can-brew`, `alchimist inv add <реагент> <кол-во>`.

**Готово, когда:** импорт реальных заметок даёт 63 реагента и 140 записей зелий, отчёт содержит известные проблемы исходных заметок, `alchimist can-brew` в консоли выводит правильный список.

> Импорт из Obsidian свою задачу выполнил и позже был удалён из приложения, см. [03 §7](03-архитектура-и-данные.md#7-импорт-из-obsidian-удалён).

> После этого этапа приложением уже можно пользоваться из терминала.

## Этап 3. MVP с интерфейсом

- `services/`: каталог, инвентарь, варка (без лаборатории), шина событий.
- `ui_qt/`: главное окно с боковой панелью, страницы **Могу сварить**, **Реагенты**, **Мои зелья**, **Справочник** (просмотр, добавление и правка реагентов, ввод рецепта в карточку зелья).
- Диалог варки (FR-7.1, FR-7.2).

Требования: FR-1.1–1.4, FR-2.1, 2.2, 2.4, 2.5, FR-3.1–3.3, FR-4.1–4.4, FR-5.1, 5.2, 5.4, 5.5, FR-7.1, 7.2, FR-10.1.

**Готово, когда:** на следующей сессии D&D можно вести инвентарь и варить в приложении, не заглядывая в Obsidian.

## Этап 4. Эксперименты и журнал

- Страница **Журнал** (FR-8.1–8.3).
- Страница **Лаборатория** (FR-7.3–7.5) с подсказкой «уже пробовали».
- «Сохранить как рецепт» из журнала.
- Повторы варианта (FR-5.3), заметки к зельям (FR-4.5).

## Этап 5. Наборы, «почти готово», обмен

- Настройки: наборы инструментов (FR-9.1), папка данных (FR-9.4).
- Страница **Почти готово** (FR-6.1–6.3).
- Экспорт и импорт справочника со сравнением (FR-10.2–10.4).
- Создание реагента из окна добавления в инвентарь (FR-3.4), скрытие вместо удаления (FR-1.5), CRUD зелий (FR-2.3), Markdown в описаниях (FR-2.6).

## Этап 6. Релиз для партии

- Локализация: вынести все строки в `.po`, выбор языка (FR-9.3).
- Сборки PyInstaller под Windows и macOS, AppImage или `pipx` под Linux, публикация в GitHub Releases по тегу.
- Короткая инструкция для игроков: установка, первый запуск, импорт справочника от ведущего игрока.
- Горячие клавиши (NFR-9).

## Потом (F)

- Особые основы (FR-11.1): `catalog/bases.json`, основа в инвентаре, `required_base_id` в рецепте, элемент основы в сумме.
- ~~Несколько персонажей (FR-11.2)~~ — сделано вместе с GM и изучением рецептов (FR-14.x).
- Броски внутри приложения (FR-11.3).
- Английский язык (FR-11.4).
- Отмена варки (FR-7.6), резервная копия в zip (FR-10.5), поиск по комбинациям в журнале (FR-8.4), сводка элементов (FR-3.5), обратные ссылки «где участвует реагент» (FR-1.6).

## Открытые вопросы к DM

Всё, что ниже, в приложении пока решено допущениями (**[Допущение]** в [01](01-правила-алхимии.md)). Каждое допущение легко поменять.

|---|---|---|
| 1 | Правило «единиц в рецепте = редкость + 1» (2…6) точно действует для редких, эпических и легендарных зелий? | Да, при несоответствии — только предупреждение |
